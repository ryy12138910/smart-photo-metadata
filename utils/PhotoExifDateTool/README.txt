Photo EXIF Date Unifier

How to use:
1. Extract the ZIP file completely. Do not run Run.cmd from inside the ZIP preview.
2. Keep Run.cmd and unify_exif_dates.ps1 in the same folder.
3. Double-click Run.cmd.
4. Select the folder containing the photos in the folder picker.
5. The processed copies will be placed beside the source folder in a new folder ending in _dates-unified.

The original photos are not modified. A processing-report.csv file records the result for every JPG/JPEG file.
