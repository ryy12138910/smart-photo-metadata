# 照片水印信息整理工具

用于批量整理工程现场、巡检、测绘等照片中的经纬度和拍摄时间。程序读取照片画面上的水印，生成可人工审核的 Excel；确认后，再把结果写入新照片的属性中。

## 背景

现场照片往往已经在画面上显示位置和时间，但文件属性中缺少这些信息。照片数量较多时，逐张查看、抄录和修改不仅耗时，也容易出现数字、方向或日期错误。

本工具把这项工作整理为一个可重复的流程：

1. 批量识别照片水印；
2. 将结果集中到 Excel 中审核；
3. 只把确认通过的结果写入新照片；
4. 保留原照片和原目录结构，便于核查与归档。

## 识别方式

- **纯 OCR（本地处理）**：照片不发送给第三方服务，适合离线或敏感数据场景。
- **OCR + 大模型 API**：用具备图片理解能力的大模型复核异常或缺失结果。API 服务商和模型不受限制，只要提供兼容的图片对话接口即可。

## 快速开始

### 使用便携包

在 GitHub Releases 下载 `PhotoMetadataTool-Windows-x64.zip`，解压后双击 `启动程序.bat`。便携包不要求安装 Python，也不需要配置环境变量或程序路径。

### 从源代码启动

双击 `启动程序.bat`。首次运行会自动准备所需组件，完成后直接打开操作界面。首次准备需要联网，之后纯 OCR 可离线使用。

## 操作流程

### 1. 识别与审核

1. 选择照片根目录；
2. 选择审核表保存位置；
3. 选择“纯 OCR”或“OCR + 大模型 API”；
4. 如果使用 API，填写完整 API 地址、模型名称和 API Key；
5. 点击“开始生成审核表”。

使用 API 时，所选模型必须支持图片输入。API Key 只提供给当前运行任务，不会写入审核表、缓存或日志。

任务结束后打开审核表，重点检查“待核”记录。修正经纬度或拍摄时间后，将确认无误的记录标记为“通过”并保存。

### 2. 写入新照片

1. 切换到“写入新照片”；
2. 选择原始照片目录、审核后的 Excel 和输出目录；
3. 第一次建议保留“仅演练”，先检查结果报告；
4. 确认无误后取消“仅演练”，再次运行生成新照片。

程序默认不修改原照片，只补充缺失属性。除非确有需要，不建议开启“覆盖已有 EXIF”。

## 输出内容

| 输出 | 用途 |
| --- | --- |
| `metadata_review.xlsx` | 集中查看、修正和确认识别结果 |
| `photos_with_exif/` | 保存补充属性后的新照片 |
| `write_result_report.xlsx` | 查看每张照片的处理状态和失败原因 |

识别过程中会在审核表旁生成断点文件。任务中断后，使用相同的照片目录和审核表位置再次运行即可继续。

## 使用建议

- 正式批量处理前，先用少量照片完成一次全流程测试；
- 输出目录不要选择原始照片目录；
- 涉及敏感照片时使用纯 OCR，或确认所接入 API 服务符合数据管理要求；
- OCR 和大模型结果都可能出错，正式归档前应完成必要的人工审核。

## 支持范围

- 识别与审核：JPG、JPEG、PNG、BMP、WebP；
- 写入照片属性：JPG、JPEG、PNG；
- 主要面向 Windows 10/11 64 位系统。

## 开发者构建

在 Windows PowerShell 中运行 `build_portable.ps1`，可生成包含离线 OCR 组件的便携压缩包。构建结果位于 `dist` 目录。仓库也包含 Windows 自动构建流程，可在 GitHub Actions 中手动运行，或通过 `v*` 标签触发。
